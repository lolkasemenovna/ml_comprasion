# Классификация тональности отзывов на русском языке (Transformers)

Fine-tuning предобученных трансформеров для 3-классовой классификации тональности (negative / neutral / positive) русскоязычных отзывов на товары маркетплейса на датасете [ai-forever/ru-reviews-classification](https://huggingface.co/datasets/ai-forever/ru-reviews-classification).

## Гипотеза

Дистиллированная мультиязычная модель (`distilbert-base-multilingual-cased`) достигнет более высокого macro-F1, чем компактная модель, предобученная специально на русском (`rubert-tiny2`), за счёт большего размера и более широкого претрейнинга — при этом обе модели будут хуже справляться с классом **neutral** из-за его имплицитной, неявно выраженной тональности.

## Данные

- 20% от каждого сплита: 9000 / 3000 / 3000 (train/val/test).
- Классы сбалансированы, дубликатов нет, длина текста не коррелирует с классом.
- Чистка данных не проводилась: субворд-токенизация трансформеров устойчива к «шуму» естественного текста (пунктуация, регистр, опечатки несут полезный сигнал).

## Модели

| Модель | Параметры | Особенность |
|---|---|---|
| `cointegrated/rubert-tiny2` | ~29M | компактная, предобучена только на русском |
| `distilbert/distilbert-base-multilingual-cased` | ~135M | мультиязычная (104 языка), дистиллят BERT |

**Fine-tuning**: тело модели инициализируется из предобученного чекпоинта и дообучается целиком; классификационная голова обучается с нуля. Learning rate намеренно маленький (1e-5), чтобы не разрушить уже выученные языковые представления (catastrophic forgetting).

Гиперпараметры: `epochs=10` (с `EarlyStoppingCallback(patience=3)` по val loss), `batch_size=64`, `max_length=512`. Лучший чекпоинт выбирается по минимальному **validation loss** (`load_best_model_at_end=True`).

## Метрики

- **Micro-F1** — эквивалент accuracy, отражает общую долю правильных ответов.
- **Macro-F1** — среднее F1 по классам без учёта их размера; чувствительна к слабым классам. Именно она используется для финального **сравнения моделей на test**, так как честнее отражает качество на неглавных классах.

## Результаты

| Модель | Эпох (факт) | Test Macro-F1 | F1 negative / neutral / positive |
|---|---|---|---|
| rubert-tiny2 | 10 (early stopping не сработал) | 0.71 | 0.70 / 0.60 / 0.83 |
| distilbert-multilingual | 8 (early stopping, лучший чекпоинт — эпоха 5) | **0.729** ✅ | 0.72 / 0.61 / 0.84 |

**Лучшая модель: distilbert-base-multilingual-cased.**

Гипотеза частично подтвердилась: distilbert обошла rubert-tiny2 по macro-F1 (небольшой, но стабильный разрыв), и обе модели демонстрируют системно более низкое качество на классе **neutral** — он чаще путается с negative/positive там, где тональность выражена неявно.

## Дальнейшие улучшения

- Обучение на полном датасете (100%), особенно ожидается прирост на классе neutral.
- Confusion matrix + анализ пересечения ошибок моделей — проверить, действительно ли модели ошибаются на разных примерах, прежде чем строить ансамбль.
- Оверсэмплинг для neutral-класса.
